# Changelog

All notable changes to 0xtools will be documented in this file.

## [0.1.0] - 2024-01-01

### Added
- Interactive TUI with keyboard-first navigation
- Full CLI with search, info, categories, installed, favorites, profiles
- ALPM/libalpm integration for Arch Linux package metadata
- BlackArch repository detection and indexing
- 35+ security tool categories with automatic classification
- Fuzzy search with weighted scoring across names, descriptions, categories, tags
- Structured search queries (category:web installed:true)
- Tool detail view with classification, dependencies, executables
- Package installation and removal with transaction previews
- Favorites system
- Profile system with curated tool collections
- Doctor command for system health checks
- Cache with atomic writes and corruption recovery
- Root launcher script for building from source
- Arch Linux PKGBUILD
- MIT/Apache-2.0 dual license
